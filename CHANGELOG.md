# Changelog

## 0.4.0 — local preview

- Added a bundled seven-observation public-data demo; exploration requires no Python setup.
- Added amino-acid germline V/J reference candidates with coverage, tied-best counts and source provenance.
- Added an independent local surface profile: hydrophobic and charged-residue SASA, connected patches, residue selection and report export. No SAbBox license is required; these descriptors are not TAP scores.
- Added column-mapping import previews, independent IMGT/Kabat numbering and CDR definitions, domain-selectable alignment and position-frequency inspection.
- Added deposited biological assembly expansion with distinct copy identities and a labeled stored-quality-field color layer.
- Added typed construct/specimen/antigen/source editing, selected-region similarity search and CSV table exports.
- Added integrity-checked content-addressed caching and keyboard navigation for tabs and sequence residues.
- Fixed restored demo-step state and packaged local documentation with embedded images for offline extension Details.
- Reworked the README, demo guide, privacy documentation and extension description around the actual research workflow.
- Retained the original R1 acceptance matrix; this preview does not claim that all R1 requirements are complete.


## 0.3.0 (local build)

- Add ANARCII IMGT numbering, scFv-domain mapping, real CDR extraction, local constant-reference matching and sequence properties.
- Add PDB/mmCIF mapping, offline 3D rendering, contacts, SASA and C-alpha superposition with explicit fit/evaluation definitions.
- Add CSV/TSV/paste input, six-frame translation, experimental conditions/censoring, reference packs, linked selections, pins, snapshots and recovery.
- Add an Activity Bar launcher, cancellable local runtime installation and real 1N8Z example data.
- Add OASis peptide identity, published TAP2 numeric populations, source-annotated disulfides and optional ImmuneBuilder CPU prediction with explicit model preparation/provenance.
- Preserve the full original requirements and document remaining gaps; this build does not complete R1.

## 0.2.0

- Publish a public GitHub Release with the tested VSIX and SHA256SUMS; add direct download and complete installation instructions.
- Add a built-in clearly synthetic example, five-minute walkthrough and explicit available/missing feature matrix.
- Apply typed notes to the project immediately, preserve record identity on asynchronous mutations and serialize host operations to prevent note loss and cross-record edits.
- Add clickable sequence-coordinate range bars, row position rulers and alignment columns that expose both original positions, including gaps.
- Save and restore selected sequence, reference and manual range. Reuse an open inspection workspace.
- Test the packaged, installed VSIX; add walkthrough, persistence and release guard regressions.
- Document and preserve the formal product requirements separately from the limited shipped R0 implementation.
