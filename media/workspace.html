Local variable-domain prediction
Fv models contain VH + VL only; VHH models contain one heavy variable domain. Constant domains, antigen and linkers are not modeled. Uses ANARCII input preparation and the four-member ImmuneBuilder ensemble with OpenMM refinement on CPU.
Preparation downloads official models once. Prediction then runs offline. B-column values represent ensemble coordinate dispersion in Å, not pLDDT.
Import local coordinates to inspect a structure.
Click two atoms to measure a distance. Rotation: drag · Zoom: scroll.
Local surface profile
An open-source descriptive alternative to proprietary scoring. Uses the selected Chain A / B in isolation (choose the same chain twice for a single domain). For Fv comparison, use equivalent Fv models. These are independent surface descriptors, not TAP scores.
Superpose structures
Fit Cα atoms mapped to the selected sequence. Choose fit and evaluation regions independently. Missing coordinates are excluded and matched input positions are saved.
