# An observation you can reproduce

**Sequence → structure → evidence**

The bundled example combines real PDB 1N8Z coordinates with locally computed numbering, reference similarity, an Fv prediction and a surface profile.

- Select CDR3 and follow its residues between views.
- Compare experimental and predicted coordinates with explicit fit and evaluation regions.
- Inspect exposed hydrophobic and charged-residue patches.
- Preserve sources and calculation conditions when saving.

The demo runs offline immediately. To calculate new results for your own data, install the optional runtime from **Workspace tools → Analysis runtime**.
