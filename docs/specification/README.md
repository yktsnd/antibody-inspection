# Formal design sources

These are the supplied v1.0 product design sources, retained in their original language and data format so development does not depend on a chat transcript. They are design requirements, not statements that the implementation exists.

- `requirements.original.ja.md`: complete formal requirements v1.0 (Japanese).
- `feature-catalog.json`: all 59 feature IDs and acceptance statements.
- `concepts.json`: proposed visual terminology dictionary.
- `sources.json`: primary/official source references used by the design.

The English [requirements and shipped-status matrix](../requirements.md) is the entry point for contributors. The actual runtime JSON format is documented in [project-format.md](../project-format.md). The target model and scientific contracts in the design are not implemented by the R0 project format.
